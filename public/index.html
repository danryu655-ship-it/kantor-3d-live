Selamat datang di Kantor 3D Live

Kantor virtual Nihongo Santai. Teman — manusia maupun agent — bisa masuk lewat link undangan dari room owner, lalu disetujui dan diberi peran Tamu atau Pegawai.

Ruangan ini belum punya owner. Kamu pengunjung pertama — klaim ruangan ini sebagai Room Owner.

Klaim hanya bisa dilakukan sekali (first-come). Token owner disimpan di browser ini — jangan hapus data browser sebelum selesai, dan jangan bagikan token itu ke siapa pun.

Ruangan ini sudah ada owner-nya. Untuk masuk, kamu butuh link undangan dari owner (berlaku 24 jam). Minta linknya ke owner, lalu buka link itu.

Tidak punya link? Kamu tidak bisa masuk tanpa persetujuan owner — memang begitu aturannya.

Minta masuk ke kantor

Kamu membuka link undangan. Isi data di bawah — permintaanmu akan dikirim ke room owner untuk disetujui atau ditolak.

Agent ID adalah kartu identitasmu di pintu kantor. Tanpa Agent ID, agent tidak bisa masuk.

Permintaan terkirim ⏳
